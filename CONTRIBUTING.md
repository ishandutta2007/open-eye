# Contributing to OpenEye

First off, thank you for considering contributing to OpenEye! It's people like you that make OpenEye such a great community.

We welcome contributions of all kinds, from new features to bug fixes, documentation, and even just spreading the word.

## How to Contribute

*   **Reporting Bugs:** If you find a bug, please open an issue on our GitHub repository. Be sure to include as much detail as possible, including your operating system, the version of OpenEye you are using, and steps to reproduce the bug.
*   **Suggesting Enhancements:** If you have an idea for a new feature or an enhancement to an existing one, please open an issue on our GitHub repository. This allows us to discuss the idea and its potential implementation.
*   **Pull Requests:** If you have a bug fix or a new feature that you would like to contribute, please open a pull request.

## Submitting a Pull Request

1.  Fork the repository and create your branch from `main`.
2.  If you've added code that should be tested, add tests.
3.  If you've changed APIs, update the documentation.
4.  Ensure the test suite passes.
5.  Make sure your code lints.
6.  Issue that pull request!

We will review your pull request as soon as possible. We may suggest some changes or improvements or propose alternate ways of implementing the feature.

Thank you for your contribution!
